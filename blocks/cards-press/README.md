# cards-press

Custom **cards** block. Purpose: list of press-release cards, each with a photo, headline, teaser and a link to the full release.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per card: cell 1 image (4:3 photo); cell 2 text (H3 headline, teaser paragraph, CTA link).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
