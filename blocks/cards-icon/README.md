# cards-icon

Custom **cards** block. Purpose: row of padded colored tiles, each with a small line icon, heading, short description and a bottom-pinned link.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per card: cell 1 icon image; cell 2 text (heading, description, CTA link).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
