# columns-image-text

Custom **columns** block. Purpose: fixed two-part media + copy row (1/3 media, 2/3 copy) where the media side alternates.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row with two cells: media cell (image, or empty for a decorative shape) and copy cell (H2, paragraphs, CTA link); cell order follows the source (image-left or image-right).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
