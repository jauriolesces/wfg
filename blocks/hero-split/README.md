# hero-split

Custom **hero** block. Purpose: top-of-page split hero with copy on one half and a hexagon-cropped photo on the other.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1: image (photo, alt text); row 2: text (H1 title, intro paragraph, CTA link).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
