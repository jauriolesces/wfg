# cards-logo

Custom **cards** block. Purpose: image-only partner/company logo grid.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per logo: cell 1 logo image (alt text = company name); cell 2 text (left empty).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
